# Herramientas opcionales

Estas dependencias son solo sugerencias para trabajar con el repositorio auxiliar:

- `curl` para consultar la API mock;
- `jq` para inspeccionar JSON;
- `docker compose config` para validar Compose;
- Mailpit en `http://localhost:8025` para comprobar emails;
- Ofelia como ejemplo de scheduler externo en `examples/ofelia-compose.yml`.
