# Carpeta de trabajo del candidato

Esta carpeta está reservada para la implementación de la solución. No contiene una solución de referencia.

Se espera que el candidato añada aquí, o reorganice según su criterio:

- módulo de API HTTP;
- módulo de worker;
- adaptadores para HTTP, SMTP, filesystem y persistencia;
- tests;
- configuración del proyecto.

La interfaz entre módulos debe ser pequeña y testeable. Las dependencias externas no deberían crearse dentro de la lógica de negocio sin una seam o adapter que permita sustituirlas en tests.
